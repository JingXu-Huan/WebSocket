📌 结论：
🔑 核心区别一览
✅ WebSocket 优势
  • 服务器可以主动推送，真正的实时
  • 连接建立后数据帧开销极小（2-10 字节头）
  • 无需重复握手，延迟极低
  • 全双工：同时收发，不互相阻塞
⚠️ HTTP 轮询的代价
  • 每次请求都带 400+ 字节 HTTP 头
  • 需要客户端主动发起，有延迟盲区
  • 每次 TCP 连接建立/断开都有握手开销
  • 服务端压力随轮询频率线性增长
📖 何时用哪个？
  • WebSocket：聊天、游戏、实时协作、股票
  • HTTP 轮询：低频数据查询、简单状态检查
  • SSE：单向推送、日志流、AI 流式输出
  • REST HTTP：无状态 CRUD 操作
