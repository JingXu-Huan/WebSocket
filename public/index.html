⚡ WebSocket 是什么？

WebSocket 是一种在单个 TCP 连接上进行全双工通信的网络协议。
它让服务器能够主动推送数据给客户端，无需客户端反复询问。

🔌 WebSocket 工作原理

握手过程（Handshake）

  1. 客户端发送 HTTP Upgrade 请求
  2. 服务器响应 101 Switching Protocols
  3. 协议从 HTTP 升级为 WebSocket
  4. 建立持久化的全双工连接
  5. 双方可以随时互相发送数据 🎉
// 客户端发送升级请求
GET /chat HTTP/1.1
Upgrade: websocket
Connection: Upgrade
Sec-WebSocket-Key: dGhl...

// 服务器响应
HTTP/1.1 101 Switching Protocols
Upgrade: websocket
Connection: Upgrade

// 连接建立！双向通信开始
WS ↔ 全双工通信通道已就绪

🚀 WebSocket 的核心特性

🔄

全双工通信

客户端和服务器可以同时互相发送数据，不需要等待对方响应，就像打电话一样。

⚡

低延迟

连接建立后，数据帧的开销极小（仅 2~10 字节），相比 HTTP 请求的几百字节头部，效率大幅提升。

🔗

持久连接

连接一次建立就保持，无需为每条消息重新握手，节省了大量的连接建立时间。

📡

服务器推送

服务器可以主动向客户端推送数据，无需客户端轮询请求，实时性极佳。
